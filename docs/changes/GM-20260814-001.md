# GM-20260814-001：Agent 注册、节点撤销与任务安全恢复闭环

日期：2026-08-14

## 变更范围

本轮把 Agent 首次注册、节点撤销、连接会话和任务重投从静态共享令牌路径收口为可由平台管理员日常运维的完整闭环，并保留旧部署的静态令牌兼容性。迁移新增一次性令牌摘要与节点撤销状态，HTTP/OpenAPI/Web 提供签发和撤销入口，Agent 用持久日志保证断线、并发重投和进程重启后的保守恢复。

## 注册与节点生命周期

- `000010_agent_enrollment` 保存注册令牌 SHA-256 摘要、可选节点名称提示、签发人、过期和消费时间；明文只在签发响应中返回一次，消费使用原子更新，重放和过期令牌均拒绝。
- 令牌默认有效期为 24 小时，显式 TTL 限制为 1 秒至 7 天，节点名称提示最多 100 个 Unicode 字符。提示当前只用于运维记录，不是对 Enroll 请求中节点名称的强绑定。
- Agent gRPC 同时接受配置的长期静态令牌和数据库签发的一次性令牌；没有配置静态令牌时仍必须提供有效的一次性令牌，不存在匿名注册路径。
- 平台管理员可通过 `POST /api/v1/agent-enrollment-tokens` 签发令牌，通过 `DELETE /api/v1/nodes/{nodeId}` 撤销节点。接口执行 session、平台管理员和 CSRF 校验，撤销成功返回 204。
- 被撤销节点不能建立新 Connect；已有连接在下一次心跳断开，节点查询、任务领取与心跳更新均排除撤销记录。重复撤销返回 `NOT_FOUND`，不会把失败伪装成成功。

## Agent 安全恢复

- Agent 的 bbolt 操作日志持久保存 payload digest、attempt、结果、结构化错误和观测快照；已完成任务可在重投时重放同一结果，digest 不一致会拒绝。
- 每个 Connect 会话拥有独立取消上下文。断线会取消心跳、日志、指标和 worker，关闭任务通道，后续重连不会被旧 worker 阻塞。
- 同一进程内对同一 in-flight operation 的多个并发重投采用结果广播，所有等待者收到同一终态，任务主体只执行一次。
- 进程重启后遗留的 `running` 记录存在未知外部副作用，统一写入不可自动重试的 `AGENT_RESTARTED_DURING_OPERATION` 终态。需要再次执行时由控制面创建新的 operation，旧 operation 不会自动重放。

## 部署与信任边界

- Agent 首次注册前必须预置 Control Plane 的 CA 根证书；CA 私钥只留在控制面。信任根缺失或不可解析时 Agent 失败关闭，不进行 TOFU，也不启用不安全跳过校验。
- `GUGU_AGENT_CA_FINGERPRINT` 可钉扎服务端证书链中的叶证书或 CA 根 SHA-256 指纹，但它只附加在正常 CA 校验之后。CA/证书轮换必须先协调分发新的根和指纹。
- 生产 Compose 将 `agent-ca-cert` 同时以只读 secret 提供给 Control Plane 与 Agent，并用 `GUGU_AGENT_ENROLLMENT_TOKEN` 只向 Agent 注入一次性令牌；`GUGU_AGENT_REGISTRATION_TOKEN` 继续表示兼容用长期静态令牌。该变量留空时控制面仍会回退已挂载的 bootstrap token，因而操作者必须继续把 bootstrap secret 视为可注册节点的高敏长期凭据。
- 撤销不会自动迁移或停止节点上的游戏进程；它阻止控制面继续信任该节点。Docker socket 和节点数据根仍是高权限生产边界，需要独立主机加固、备份与人工恢复流程。

## 验证范围

- Store、Agent RPC、HTTP API 和 Agent 定向 Go 测试覆盖令牌单次消费/过期/重放、未知与撤销节点、心跳断开、证书轮换提示、断线重连、并发重投、日志重放、孤儿 running 记录及信任根/指纹校验。
- Web 测试覆盖签发请求、明文一次性展示/复制、撤销成功后移除，以及撤销失败时保留节点并显示错误；OpenAPI 生成类型无漂移。
- `go test ./... -count=1` 与 `go vet ./...` 通过；迁移 dry-run 连续校验 000001-000010 共 10 对 up/down。
- Web 共 18 个测试文件、217 项 Vitest 通过，`npm run typecheck`、`npm run build`、`npm run api:lint` 和 `npm run api:check` 通过。构建保留既有的单 chunk 超过 500 kB 警告。
