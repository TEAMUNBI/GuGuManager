# GM-20260808-010：GameDefinition 目标路径安全门禁

日期：2026-08-08

## 变更范围

本切片为 GameDefinition 的 variable file binding 与安装 Artifact destination 增加确定性的跨平台静态路径门禁，避免未来 Agent/安装器把清单目标解释到服务器数据根之外或按不确定顺序覆盖同一文件。

## 已实现

- `gamectl lint` 读取 `variables.bindings[].path` 与 `install.artifacts[].destination`。
- 两类目标复用开发文件 API 的可移植相对路径规范化，拒绝 `..`、POSIX 绝对路径、Windows 盘符、UNC、NUL、空清理结果、超长总路径和超长分量。
- Bundle 清单进一步只接受规范 `/` 表示，拒绝反斜杠、`./`、重复分隔符等跨平台歧义写法。
- Artifact destination 按规范路径判重，拒绝多个制品依赖声明顺序覆盖同一目标。
- 错误包含 `variables.bindings[i].path` 或 `install.artifacts[i].destination`，不解析或暴露宿主绝对路径。
- 游戏包文档修正 argument binding 示例：`runtime.command.args` 使用精确 `{{ memory_mb }}` 槽位，binding template 使用 `{{ value }}` 渲染单个最终参数。

## API、数据库与安全影响

- REST API、OpenAPI、数据库和权限键没有变化。
- 这是发布前静态拒绝门禁；没有执行写文件、下载或安装副作用。
- 清单中此前被接受的非规范或危险目标现在会被拒绝，这是有意的 v1alpha1 安全收紧。

## TDD 与验证结果

- 红灯：新增测试证明父目录、绝对路径、盘符/UNC、NUL、`.`、反斜杠、非规范分隔符、长度超限和重复 Artifact destination 此前均被错误接受。
- 绿灯：实现统一 helper 后，危险路径测试、重复目标测试和 `paper.jar`、`mods/plugin.jar`、`config/server.properties` 正例通过。
- Mutation：临时禁用 Artifact 循环，Artifact 危险路径与重复目标测试重新失败；临时禁用 file binding 分支，其危险路径测试重新失败。恢复实现后定向测试通过。
- `go test ./cmd/gamectl ./internal/files -count=1`：通过。
- PaperMC、Factorio、Vintage Story 三份示例 lint：通过。
