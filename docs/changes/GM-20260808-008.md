# GM-20260808-008：日志与开发部署硬化

日期：2026-08-08

## 变更范围

本切片修正 Control Plane 已声明但未实际应用的日志配置，并让开发容器构建包含 Go 编译所需的契约文件、全新 PostgreSQL volume 初始化两份迁移。

## 已实现

- Control Plane 在配置加载成功后按 `GUGU_LOG_LEVEL` 的 `debug/info/warn/error` 和 `GUGU_LOG_FORMAT` 的 `json/text` 构造 logger；配置加载失败仍使用安全的 bootstrap JSON/info logger。
- `.env.example` 明确给出开发日志级别与格式默认值。
- Docker build stage 在编译前复制 `spec/`，满足当前 Go embed/import 依赖。
- Compose 的全新 PostgreSQL 数据卷按编号挂载 `000001_core.up.sql` 与 `000002_identity.up.sql`。
- CI 增加 Control Plane 开发镜像构建 job，防止 Dockerfile 与编译输入再次漂移。

## API、数据库与配置影响

- REST API 与权限无变化。
- 日志配置从“仅校验”变为实际生效；默认仍是 JSON/info。
- Compose 只改变全新 volume 的初始化脚本集合；已有 PostgreSQL volume 不会自动升级，仓库仍没有生产 migrator。

## 验证结果

- logger 测试覆盖 debug JSON 输出，以及 warn text 的级别过滤；移除配置应用的 mutation 会使测试失败，恢复后通过。
- `go test ./... -count=1` 与 `go vet ./...`：通过。
- GitHub Actions 工作流由 `actionlint v1.7.12` 静态校验通过。

## 未完成或未验证范围

- 本机没有 Docker，未实际构建镜像、启动 Compose 或验证健康检查；这里只验证了源文件、Go 构建与 CI 工作流静态配置。
- 已有数据库 volume 的升级、失败回滚、备份和生产发布编排仍未实现。
- 工作区没有 `.git`，没有可记录的 CI run、branch、commit 或 PR。
