## 契约与兼容影响

- REST：新增 `/api/v1` 开发切片 OpenAPI；异步服务器创建、电源和备份受理审计使用 `accepted`，不表示 operation 已成功；当前与生产目标的差异记录在 `docs/design/08-api-contracts.md`。
- Agent：新增 `gugumanager.agent.v1` Proto 目标契约；typed task payload、类型匹配、PKCS#10 CSR、叶证书优先的证书链和独立根 CA trust bundle 的互操作约定记录在 `docs/design/05-agent-runtime.md`；当前 `cmd/agent` 仍只实现开发 HTTP 心跳。
- GameDefinition：新增 `gugumanager.io/games/v1alpha1` Schema，并由 `gamectl lint` 在本地执行；`metadata.version` 表示定义版本，必填 `spec.release.version` 表示上游游戏版本，深层制品和生命周期语义仍待实现。
- REST：`GameDefinition.gameVersion` 与 `Server.gameDefinitionVersion/gameVersion` 明确区分定义版本和上游版本；服务器仍以 `gameBundleDigest` 作为不可变执行身份。
- 数据库：新增 `000001_core` up/down 迁移，Bundle 分别持久化 `definition_version` 与 `game_version`，审计结果约束包含异步 `accepted`；当前 Control Plane 尚未接入 PostgreSQL。
- 配置：当前只接受 development 配置；生产配置会启动失败。Compose 宿主端口默认绑定回环地址，公开默认凭据只用于本机开发。
- 兼容性：当前版本为 `0.1.0` 开发契约，没有稳定生产兼容承诺；后续破坏性变化需要 ADR 和迁移说明。
