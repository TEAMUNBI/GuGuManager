# GM-20260807-004

- 时间：`2026-08-07 20:44:39 +08:00`
- 目标：在不伪装生产适配器的前提下，推进 Identity、文件、备份和节点状态的可验证开发垂直能力。
- 兼容性：扩展 `0.1.0` 开发 REST 契约；没有稳定生产兼容承诺。

## 实现概览

- 新增 Argon2id PHC 密码模块；开发管理员口令不再保存 SHA-256。Session Token 仅以内存 SHA-256 摘要索引，过期会话不能通过 CSRF。
- 登录按规范化账号和直接来源 IP 双维度限流，5 分钟内 5 次失败后阻断 15 分钟，并返回 `429` 与 `Retry-After`。
- 生产配置先聚合校验 HTTPS Public URL、PostgreSQL URL、TLS 终止声明和 Secret/Agent CA 文件，再以 `ErrProductionAdapterUnavailable` 硬失败，禁止回退到内存适配器。
- 新增 `cmd/migrate plan`，校验迁移 up/down 配对、连续版本和 SHA-256；该命令明确不连接数据库、不执行 SQL。
- 新增每服务器 `ServerFS`：安全目录列表、有限读取、原子写入、建目录、移动和递归删除；阻止绝对路径、任何 `..`、链接、设备名、非常规文件和根目录变更。
- 新增文件 REST 端点和 React 文件管理交互，包括文本编辑、新建文件/目录、移动/重命名和删除确认；浏览器 Mock 保持行为一致。
- 新增备份恢复与删除 operation、幂等作用域、完整 SHA-256 元数据登记、停服恢复、排他恢复锁、generation 收敛和受理/终态审计。
- 新增 30 秒节点离线对账；Overview/Servers/Nodes 读取和 5 秒后台 sweep 会传播 offline 到服务器，新建、电源、备份和恢复任务拒绝离线节点。
- 修复 generation 过期恢复误伤恢复点、production logout Cookie 缺少 `Secure`、文件请求必填成员未执行、登录限流表无界增长，以及 HTTP 会话在网络抖动时误切浏览器 Mock。
- 文件页把条目绑定到实际加载路径，失败时清空旧条目并提供重试；备份页保持服务器级锁直到 operation 终态，持续读取失败时保留 operation 身份并提供 `Retry status`。
- Modal 使用 Portal、唯一 ARIA 关联、背景 inert、滚动锁、焦点陷阱和可靠的触发元素焦点恢复；文件/备份移动端关键触控目标达到 44 CSS 像素。
- 扩展 OpenAPI、数据库约束、开发数据卷、Docker 非 root 可写目录以及拆分后的设计/开发文档；数据库和内存排他任务集合统一为 10 种类型。

## 当前边界

- 文件操作落在 Control Plane 的开发数据根，不经过 Agent，也没有流式上传、下载、解压、磁盘配额或真实节点目录句柄。
- 备份只实现内存元数据和状态机，没有生成、读取、校验或恢复真实归档；登记摘要不能替代制品内容校验。
- Identity、限流、operation、备份元数据和审计仍位于单进程内存；没有 Bootstrap Token、PostgreSQL Session、Redis 或资源级 RBAC。
- 节点仍使用开发 HTTP Bearer 心跳；没有注册令牌、CSR、mTLS/gRPC、证书轮换或吊销。
- OCI Runtime、真实容器、端口分配和资源限制仍未实现。
