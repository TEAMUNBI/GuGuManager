# GM-20260807-005：Network 与 Startup 开发适配器收口

日期：2026-08-07

## 变更范围

本次变更完成了 Network 与 Startup 的可运行开发适配器垂直切片，并将前端 Mock、HTTP 适配器、固定 GameDefinition Bundle 和设计文档对齐。

## 已实现

- Network 支持 Allocation 查询、创建、切换 primary 和删除 secondary。
- Network 保持单一 primary，拒绝 `0.0.0.0`、`::` 等 wildcard `bindIp`，同一节点上的精确 endpoint 冲突返回 `409 PORT_CONFLICT`。
- Network 与 Startup 写入使用十进制服务器 `generation` 做 fencing；过期写入返回 `412 PRECONDITION_FAILED`，成功受理会递增 generation 并创建模拟 `reconcile` operation。
- Startup 从服务器固定 `gameBundleDigest` 对应的嵌入 Bundle 派生命令、变量、默认值、类型约束、枚举和 Secret 身份，不再按 Game ID 手写 Schema 分支。
- 当前 Bundle 支持 `string`、`integer`、`boolean`、枚举、必填项、长度和数值范围校验。
- Secret 响应只暴露 `hasValue`，不返回 `value` 或 `default`；Secret 可以替换或清除。
- 含 Secret 的幂等摘要使用进程随机密钥的 HMAC-SHA256。该摘要不是生产加密存储，也没有实现 Secret Manager、句柄化传递或持久安全模型。
- 固定 Bundle 已固化并由 Go 与前端共同引用：
  - PaperMC：`sha256:412759ce8b7832b3762d1a6f34d076ecceebd4ecd7cd7d04f16ac0cff063285b`
  - Factorio：`sha256:d2e03e9dac2b301923b6ebe0e949ceea33420bfb44767c07376d5ffb34c5b62e`
  - Vintage Story：`sha256:c2c2cdb82e9ba2cc69e17b9acc99ddd4e75a40dd091e39a19c987927273e7779`
- HTTP、Mock 和前端错误模型统一结构化错误码；Startup 保存使用 Startup 快照中的 generation，并在受理 operation 完成后等待服务器刷新。
- Network 和 Startup 在节点 offline 时禁用或拒绝写入，移动端 IPv6 Allocation 地址使用 `[address]:port` 形式显示。

## 生产缺口

本次交付不是生产 MVP，也不是完整 Pterodactyl 替代品。当前适配器使用进程内存期望状态和模拟 operation，不提供真实 Docker/OCI 容器、真实 Agent 端口绑定、PostgreSQL 持久化事务、Redis 队列、Outbox、mTLS/gRPC、WebSocket 控制台、真实备份制品或生产 Secret 加密存储。多端口 Bundle 的 `portRef`/`containerPort` 映射、资源级授权、持久审计和本地密码重置闭环仍属于后续生产里程碑。
